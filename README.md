# ☕ Eucalyptus Cafe Web Project

A modern, responsive, and minimalist front-end web project for Eucalyptus Cafe, fully structured, optimized, and deployed using cloud infrastructure.

---

## 🌐 Live & Code Access

* GitHub Repository (Source Code): [Click Here](https://github.com/Sepehrfallah/eucalyptus-cafe)
* Live Demo (GitHub Pages): [Launch Eucalyptus Cafe](https://sepehrfallah.github.io/eucalyptus-cafe/)

---

## ✨ Project Features

* Responsive Design: Seamlessly adapts to all screen dimensions (Mobile, Tablet, and Desktop) utilizing responsive grid systems.
* Standard Front-End Architecture: Modular and clean file directory system for high readability, easy maintenance, and scalability.
* Custom Typography: Smooth integration and optimization of custom web fonts via CSS @font-face rules.
* Separation of Concerns: CSS styles are decoupled entirely from HTML structures to optimize asset loading speeds and performance.

---

## 📁 Project Directory Structure

The project follows a standard production-ready folder architecture with relative path linkages:

```text
├── 📁 CSS/                 # Custom styling decoupled per page
│   ├── 📄 style1.css       # Specific styles for Home Page (index)
│   └── 📄 style2.css       # Specific styles for Products/Menu (index3)
├── 📁 font/                # Web font assets (FarYas, FarZar, FarDiplomat)
├── 📁 img/                 # Graphical assets, menu pictures, and logos
├── 📄 index.html           # Main Entry Point / Home Page
├── 📄 index3.html          # Products & Menu Page
├── 📄 bootstrap.min.css    # Core Bootstrap 5 framework styles
├── 📄 bootstrap.bundle.min.js # Bootstrap interactive components & JS logic
└── 📄 168-GraFa.eps        # Vector source asset
